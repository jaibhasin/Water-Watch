# 🌊 Water-Watch

**A community-driven platform for reporting and addressing water contamination and wastage issues.**

![Water Watch](https://img.shields.io/badge/Version-1.0-blue.svg)
![Flask](https://img.shields.io/badge/Flask-2.3.3-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

## 🌟 Overview

Water-Watch is an innovative web application that empowers communities to actively participate in water conservation and contamination prevention. We've all witnessed instances where water is being wasted unnecessarily in public places due to leaks, faults, or where water bodies are being polluted. These problems sometimes get resolved quickly, but often take too long, leading to significant water waste and environmental damage.

Our platform provides a simple yet effective solution: **See it, Report it, Fix it.**

## ✨ Features

### 🚨 Issue Reporting
- **Photo Upload**: Capture and upload images of water-related issues
- **Detailed Descriptions**: Provide comprehensive details about the problem
- **Severity Classification**: Categorize issues by urgency (Low, Medium, High)
- **Location Tracking**: Pin exact locations using geolocation or manual entry
- **Instant Reporting**: Quick form submission to alert authorities

### 🗺️ Interactive Map
- **Real-time Visualization**: View ongoing water issues across India
- **Location Markers**: See reported issues with detailed popups
- **Geographical Overview**: Understand regional water challenges

### 💬 Community Engagement
- **Comment System**: Discuss solutions and collaborate on cleanup efforts
- **Community Discussions**: Share ideas and coordinate local initiatives
- **Collective Problem-Solving**: Harness community wisdom for effective solutions

### 📧 Educational Content
- **Newsletter Subscription**: Stay updated with water conservation tips
- **Weekly Quizzes**: Test your knowledge about water conservation
- **Informative Articles**: Learn about environmental protection
- **Educational Videos**: Visual content for better understanding

## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- pip (Python package installer)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/jaibhasin/Water-Watch.git
   cd Water-Watch
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash
   cd "Tackling Water Contamination and Wastage"
   python main.py
   ```

4. **Access the application**
   Open your web browser and navigate to `http://localhost:5000`

## 🛠️ Technology Stack

- **Backend**: Flask (Python web framework)
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Bootstrap 5.3.2
- **Mapping**: Leaflet.js with OpenStreetMap
- **Icons & Assets**: Custom assets and imagery

## 📱 How to Use

### Reporting an Issue

1. **Navigate** to the homepage
2. **Fill out** the "Report An Issue" form:
   - Upload a clear image of the problem
   - Provide a detailed description
   - Select the severity level
   - Add location information (auto-detect or manual entry)
3. **Submit** the report
4. **Confirmation** message will appear upon successful submission

### Viewing Active Issues

1. Click on **"Active Issues"** in the navigation
2. Browse through reported problems in your area
3. Click on any issue for detailed view
4. **Add comments** to contribute solutions or updates

### Community Participation

1. **Subscribe** to our newsletter for updates
2. **Engage** in discussions on issue pages
3. **Share** the platform with friends and neighbors
4. **Participate** in local cleanup initiatives
